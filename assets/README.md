# Assets Directory

## Images

### Required Images for Onboarding

1. **motorcycle-illustration.png**
   - Size: 384x384px (square)
   - Style: Neobrutalist motorcycle illustration
   - Format: PNG with transparency
   - Location: `/assets/images/motorcycle-illustration.png`
   - Description: A stylized, high-contrast illustration of a modern motorcycle with grayscale effect

### Placeholder Images

For development, you can:
1. Download a motorcycle image from the Stitch design
2. Or use a placeholder from https://placeholder.com/384x384
3. Place it in `/assets/images/motorcycle-illustration.png`

## Icons

App icons will be generated and placed here:
- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon
- `splash.png` - Splash screen
- `favicon.png` - Web favicon
- `notification-icon.png` - Notification icon

## Fonts (Optional)

If using custom fonts:
- Space Grotesk Bold
- Plus Jakarta Sans (Regular, Medium, Bold)
- Inter (Regular, Medium)

Place font files in `/assets/fonts/` and load them with `expo-font`.
